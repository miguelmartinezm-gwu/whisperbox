Privacy-preserving fraud scoring — Mojo + Niobium Fog FHE + Modular Cloud
How this works: a frozen sample transaction is scored by computing an encrypted dot product against a fraud centroid — the computation runs on real FPGA hardware under fully homomorphic encryption, so the server never sees the plaintext feature values. Only the final score is decrypted, and the AI narration below is written from that number alone — it never sees the original data.
Running real encrypted computation on Niobium Fog — this takes 15–25 seconds.
1. Mojo validates and computes the clear-text reference score
2. Features are encrypted and submitted to Fog FPGA hardware
3. The encrypted score is computed and returned, then decrypted
4. Modular Cloud (MiniMax) narrates the decrypted number only
